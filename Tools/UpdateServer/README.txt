# HotUpdateServer demo folder

This folder is the "remote update server" of the demo.

`lua/` and `version.json` here are generated by the editor menu
`HotUpdate > Publish to Update Server (demo)`.

Serve this folder over HTTP and point the game at it
(`Assets/StreamingAssets/hotupdate.txt`):

    python -m http.server 8000

or double click `start_server.bat` (Windows).

Then in the running game press the "Check update" button (or Editor dev
console "Check Update"). Editing `Assets/Lua`, re-publishing and pressing
check again shows the change live - no rebuild needed.
